# APBD - Ćwiczenia 1: Wprowadzenie do Gita

## Opis projektu
Prosta aplikacja konsolowa napisana w języku C# (.NET) demonstrująca podstawy pracy z systemem kontroli wersji Git. 
Program wyświetla powitanie oraz oblicza sumę elementów zdefiniowanej tablicy liczb całkowitych za pomocą klas pomocniczych `Greeting` i `StatisticsHelper`.

## Wymagania
* .NET SDK 8.0 (lub nowszy)

## Uruchomienie programu
Aby skompilować i uruchomić projekt, wykonaj poniższe polecenie w katalogu głównym:

```bash
dotnet run
